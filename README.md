# Cold-Gas-Thruster

손바닥 장착형 냉가스 추진 장치(아이언맨 리펄서 스타일) 제작 프로젝트.
압축공기를 초킹 노즐로 분사해 실제 추력을 내는 것이 목표다. 연출용 소품이 아니라 측정 가능한 출력이 나오는 하드웨어를 지향한다.

## 현재 단계: Phase 1 — 추력 측정 테스트 리그

본 제작에 들어가기 전에, 저압(3~5 bar)에서 노즐 지름별 추력과 밸브 응답 시간을 실측하는 단계.
계산 모델의 예측과 실측을 비교해 방출계수(Cd)를 도출하고, 그 데이터로 Phase 2 사양을 확정한다.

### 로드맵

- [x] Phase 0 — 이론 학습, 추력 계산기 작성, 부품 선정/주문
- [ ] Phase 1 — 테스트 리그 조립, 측정 매트릭스 (노즐 3/4/5mm × 압력 3/4/5bar × 펄스 100/200/500ms)
- [ ] Phase 2 — 실측 기반 사양 확정, 고압 구성 (레귤레이터 + 고속 밸브)
- [ ] Phase 3 — 팔뚝 브레이서 + 손바닥 하우징, LED/사운드/IMU 통합

## 파일 구성

| 파일 | 설명 |
|---|---|
| `calculator.py` | 추력 계산기. 이상기체 + 초킹 유동 기반. 탱크 스펙과 노즐 치수를 넣으면 가스 질량, 유량, 추력, 지속시간, 발사 횟수를 출력 |
| `repulsor_test_rig.ino` | ESP32 측정 리그 펌웨어. HX711 80Hz 샘플링, 솔레노이드 펄스 구동, 데드맨 스위치, 발사별 피크 추력/총역적/응답시간 자동 산출 |
| `thrust_rig_mount.scad` | 로드셀 마운트 파라메트릭 설계 (OpenSCAD). 수직 캔틸레버 배치, 부품 실측 후 파라미터 수정해서 사용 |
| `checklist.txt` | Phase 1 부품 목록, 조립 순서, 안전 규칙 |

## 물리 모델

- 탱크 가스 질량: 이상기체 법칙 ρ = P/(R_specific·T)
- 질량유량: 초킹 유동 (노즐 목 마하 1 고정, 유량은 P0와 At에 비례)
- 추력: F = ṁ·v_t + (P_t − P_atm)·A_t — 수렴 노즐이라 출구 속도는 음속이 상한, 압력항이 추력의 약 40%를 담당
- 예측 성능 (13ci HPA + 9 bar 레귤레이터 + 4mm 노즐 기준): 추력 ~14 N, 0.2 s 펄스 약 9발

참고 자료: NASA Glenn Beginner's Guide to Aeronautics (compressible flow), Sutton & Biblarz *Rocket Propulsion Elements*

## 안전

- 압력용기는 인증된 기성품만 사용. 자작 금지
- Phase 1은 탱크 정격의 70% 이하로만 가압
- 발사 시 노즐 전방 1 m 이격, 보안경 착용
- 밸브 전원은 데드맨 스위치 경유 — 손을 떼면 즉시 차단
- 압축공기를 신체에 직사하지 않는다 (근거리 제트는 피부 관통·색전 위험이 실재함)
- 연소식(가연성 가스) 구성은 이 프로젝트 범위에서 제외
